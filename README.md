# Natural Language Processing (ITNPA3T34) – Project 1

## About the Project

This repository contains the work completed for Project 1 of the Natural Language Processing (NLP) module.

The project applies NLP techniques using Python to analyse research abstracts and articles. It includes the project documentation, datasets, Jupyter notebooks and a deployment folder.

## Repository Structure

| Folder/File | Description |
|---|---|
| `documentation/` | Project documentation covering Questions 1–4 |
| `datasets/` | Research abstracts and research article corpus |
| `notebooks/` | Separate Jupyter notebooks for Questions 1–4 |
| `deployment/` | Streamlit application and deployment instructions |
| `outputs/` | Generated visualisations and other project outputs |

## Questions Covered

- **Question 1:** Project analysis and related NLP tasks.
- **Question 2:** Research abstract classification and web application.
- **Question 3:** Text preprocessing and text summarisation.
- **Question 4:** Topic modelling using Latent Dirichlet Allocation (LDA).

## Technologies Used

- Python
- Jupyter Notebook
- NLTK
- Scikit-learn
- Streamlit
- Matplotlib
- pyLDAvis
