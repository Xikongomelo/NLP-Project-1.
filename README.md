# Xikongomelo-Max-Mabunda-ITNPA4-34-Project-1-Eduvos-Online-2026
Applied Natural Language Processing (NLP) techniques to analyse research articles using Python. The project involved text preprocessing, extractive text summarisation using TextRank, and topic modelling with Latent Dirichlet Allocation (LDA), supported by interactive visualisations using pyLDAvis.
